# Demo dosyaları

`emails/` içindeki `.eml` dosyaları demo için uydurulmuş e-postalar (alan adları `.example`,
gerçek mağaza ya da kişi yok). Gelen kutusu sayfasında **E-posta yükle (.eml)** ile yüklenir.

| Dosya | Ne gösteriyor |
| --- | --- |
| `01-kitap-siparisi.eml` | Sipariş e-postası: mağaza, kalemler ve 404,40 TL toplam okunur, onay bekler. |
| `02-kampanya-bulteni.eml` | Bülten: alışveriş değil, "yoksayıldı" olarak kalır. |
| `03-yemek-siparisi-sahte-talimat.eml` | İçinde "otomatik onayla" yazan bir sipariş. Kasa tutarı okur ama hiçbir şeyi kendisi onaylamaz. |
